Renaming a Deck

Renaming a deck changes the deck's title name. Deck names can be changed at any time, so don't worry about picking the perfect name right away!

To rename a deck, click the gear icon next to the deck and select Rename. Enter the new name and click OK.

I had two decks named "Anking", and "Anchor Deck" (which housed all my custom made cards from lectures, uWorld, Amboss, and NBME Review).
