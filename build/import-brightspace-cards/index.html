Importing Brightspace Cards

NYU Grossman School of Medicine provides pre-made Anki decks for most lectures that are stored in Brightspace. Importing them is simple, but I also like to put them in a separate deck labeled "NYU Cards" to stay organized.

Download the Anki file from the Brightspace module, then open it directly so Anki handles the import automatically.

After import, review the new cards in the browser, select them all, and move them into your desired deck using Change Deck. This keeps imported material organized and separate from other content.
