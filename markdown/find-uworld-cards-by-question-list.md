## Getting Cards by uWorld Question List

After completing a uWorld question set, you can retrieve AnKing cards for **ALL** questions in that block at once using the built-in question list. 

I did not use this feature often because I used tutor mode when using question banks. I forced myself to review the question as I got it write/wrong and look for questions/additional resources at a question-by-question level. I found that questions could get lost in the cracks if I waited until a set of 40 to review them.

From the review screen, open **Question List** and copy the full set of question IDs shown.

Open Anki, go to **Tools > Find cards from uWorld Test** (requires the add-on), and paste the copied IDs into the input field.

Anki will return all cards linked to those questions. You can review the results and selectively **Toggle Suspend** to activate only the cards you want for study.
