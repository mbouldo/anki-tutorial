## Getting Cards from uWorld Question (Addon)

Instead of manually searching by question ID, you can use an add-on that automates retrieval of AnKing cards linked to uWorld questions.

First, locate the add-on by searching for “Find cards from UWorld test” and copy the provided add-on code.

Open Anki and go to **Tools > Add-ons > Get Add-ons**, then paste the code and confirm installation. Restart Anki after installation so the new menu option appears.

Once installed, open **Tools > Find cards from UWorld test**, paste one or more question IDs (for example `3110, 9810`), and run the search.

The matching cards will appear. Select the ones you want and **Toggle Suspend** to activate them to study.
