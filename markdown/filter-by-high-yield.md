## Filtering by High Yield

High Yield tags in AnKing are used to mark cards that are more commonly tested on Step 1 or 2. Filtering by these tags helps reduce workload while still performing well, based on the 80-20 rule (80% of testable material only comes from 20% of the content). When studying, I found this to be true! Most of passing Step 1 is knowing bread & butter high yield cards.

Start by selecting a set of cards (for example via tag tree, spreadsheet, or copied tags). This will return a broader set of cards.

Copy the **High Yield** tag and append it to your existing search query in the Browser using a space. Anki will then narrow the results to only cards that carry both filters.

`tag:#AK\_Step1\_v12::#Low/HighYield::1-HighYield`

From there, review the reduced set of cards, select the ones you want, and **Toggle Suspend** to move them to your active rotation.
